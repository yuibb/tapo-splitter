# Tapo録画ファイル スプリッター

Tapoシリーズのカメラで録画したMP4を、カメラ映像内の日時OSD（画面表示）から読み取り、録画中に時刻がジャンプした位置で分割するPythonツールです。

フォントデータは配布物に内蔵しません。初回利用時に、利用者自身の録画からOSDテンプレートJSONを作成します。

## 注意点

分割位置はMP4のGOP（キーフレーム）単位です。そのため、指定したジャンプ位置に対して、分割ファイルの先頭・末尾が数フレーム程度前後することがあります。

元のMP4は変更しません。映像・音声を再エンコードせずストリームコピーしてMOVへ切り出します。

OSDの位置は、現在のTapo録画に合わせて画面左上の幅950px・高さ70pxに固定しています。別の解像度・機種・表示位置でOSD認識が不安定な場合は、映像に合わせてOSD範囲の設定を調整してください。

## 出力ファイル名

```
YYYYMMDD_HHMMSS_分数.mov
```

- `YYYYMMDD_HHMMSS`: OSDから読み取った、その区間の開始日時
- `分数`: 区間の長さを30秒単位で丸めた表示値（例: `2.5`）
- 録画停止が疑われる区間には末尾に `_Err` が付きます
- 同名ファイルがある場合は `_part02` のような連番が付きます

各MP4について、同じ出力フォルダに処理結果の一覧（`.md`）も作成します。

## 必要環境

### 動作確認済み環境

本プロジェクトのテスト環境で、Tapo録画MP4に対するOSD認識・時刻ジャンプ検出・GOP単位分割を確認済みです。

- macOS
- Python 3.10以上
- ffmpeg / ffprobe
- OpenCV（ヘッドレス版）
- NumPy

### 必要なファイル・条件

- 対応動画形式はMP4です
- OSD（日時表示）が映っている録画が必要です
- 録画フォルダと出力フォルダへの読み書き権限が必要です
- 分割後ファイルを書き出す空き容量が必要です
- 初回設定とJSON作成はターミナルで行います

### macOS

Pythonを実行でき、`pip`が使える環境を前提とします。

```bash
python3 -m pip install opencv-python-headless numpy
brew install ffmpeg
```

### Windows

Pythonを実行でき、`pip`が使える環境を前提とします。PowerShellまたはコマンドプロンプトで実行してください。

```powershell
py -m pip install opencv-python-headless numpy
winget install --id Gyan.FFmpeg.Shared -e
```

インストール後、新しいターミナルを開いて`ffmpeg`と`ffprobe`が実行できることを確認してください。

## 使い方

同じフォルダに必要なPythonファイルを置き、実行用の`run_tapo_splitter.py`を起動します。利用者が実行するのはこのファイルです。

```bash
python3 run_tapo_splitter.py
```

Windowsでは次のように起動できます。

```powershell
py run_tapo_splitter.py
```

コマンド入力なしで起動する場合は、Macでは`run_tapo_splitter.command`、Windowsでは`run_tapo_splitter.bat`をダブルクリックしてください。ランチャーは同梱または親フォルダの仮想環境を優先し、なければ通常のPythonを使用します。Macで初回だけ開けない場合は、ファイルを右クリックして「開く」を選びます。

初回起動時はターミナル上で、録画データフォルダ、分割結果の出力フォルダ、OSDテンプレートJSONの場所を対話式に指定します。JSONがない場合は録画からサンプル画像を抽出し、表示された日時の正解文字列を入力してテンプレートを作成します。

OSDが映っていない、または14桁の日時を切り出せない録画では、テンプレートJSONを作成できず処理を中止します。その場合はOSDが表示されている録画を用意して再実行してください。

設定ファイルに3項目が保存された後は、次回から初期設定を省略して本番の分割処理を開始します。

## 動作の概要

1. 録画映像からOSD領域を切り抜き、利用者が確認した日時文字列と一緒にテンプレートJSONを作成します。
2. そのJSONを使って録画ファイル内の日時OSDを順に読み取ります。
3. 映像上の経過時間とOSD時刻の差を調べ、時刻が不連続になった位置をジャンプとして検出します。
4. 検出位置を基準に、MP4をGOP単位でストリームコピーして分割します。
5. 分割一覧と、録画停止が疑われる区間の情報をMarkdownで保存します。

## ライセンスについて

このツールは利用者の録画から作成したテンプレートJSONを使用します。特定フォントのデータを配布物へ同梱しないため、フォントライセンスに依存しない構成です。

# Tapo録画ファイル スプリッター

Tapoシリーズのカメラで録画したMP4を、映像内の日時表示（OSD）から読み取り、録画中に時刻がジャンプした位置で分割するPythonツールです。

標準設定はTapo C230の3K録画（2880×1620）です。カメラや解像度ごとの読み取り設定と、その環境用の数字の見本は1セットで管理します。初回利用時に、利用者自身の録画から数字の見本データを作成します。

## 注意点

分割位置は動画内部の区切り位置の都合で、指定したジャンプ位置に対して、分割ファイルの先頭・末尾が数フレーム程度前後することがあります。

元のMP4は変更しません。映像・音声を再エンコードせずストリームコピーしてMOVへ切り出します。

日時表示は、現在の標準設定では画面左上から読み取ります。別の解像度・機種・表示位置で読み取りが不安定な場合は、その映像に合わせた読み取り設定を作成してください。

## 出力ファイル名

```
YYYYMMDD_HHMMSS_動画長さ.mov
```

- `YYYYMMDD_HHMMSS`: OSDから読み取った、その区間の開始日時
- `動画長さ`: 区間の長さを30秒単位で丸めた表示値（例: `2.5`）
- 録画停止が疑われる区間には末尾に `_Err` が付きます
- 同名ファイルがある場合は `_part02` のような連番が付きます

各MP4について、同じ出力フォルダに処理結果の一覧（`.md`）も作成します。

## 必要環境

### 動作確認済み環境

本プロジェクトのテスト環境で、Tapo録画MP4に対する日時表示の読み取り・時刻ジャンプ検出・画質を変えない分割を確認済みです。

- macOS
- Tapo C230
- 録画解像度 2880×1620
- Python 3.10以上
- ffmpeg / ffprobe
- OpenCV（ヘッドレス版）
- NumPy

### 必要なファイル・条件

- 対応動画形式はMP4です
- OSD（日時表示）が映っている録画が必要です
- 録画フォルダと出力フォルダへの読み書き権限が必要です
- 分割後ファイルを書き出す空き容量が必要です
- 初回設定とJSON作成はターミナルで行います

標準設定はTapo C230の3K録画です。2K録画や別機種を使用する場合は、その映像に合わせた読み取り設定と数字の見本を作成してください。

### macOS

Pythonを実行でき、`pip`が使える環境を前提とします。

```bash
python3 -m pip install opencv-python-headless numpy
brew install ffmpeg
```

### Windows

Pythonを実行でき、`pip`が使える環境を前提とします。PowerShellまたはコマンドプロンプトで実行してください。

```powershell
py -m pip install opencv-python-headless numpy
winget install --id Gyan.FFmpeg.Shared -e
```

インストール後、新しいターミナルを開いて`ffmpeg`と`ffprobe`が実行できることを確認してください。

Pythonや依存ライブラリの導入に慣れていない場合は、READMEをCodexなどのAIコーディング支援へ渡し、環境確認とインストール手順を案内してもらう方法をおすすめします。

## 使い方

同じフォルダに必要なPythonファイルを置き、実行用の`run_tapo_splitter.py`を起動します。利用者が実行するのはこのファイルです。

```bash
python3 run_tapo_splitter.py
```

Windowsでは次のように起動できます。

```powershell
py run_tapo_splitter.py
```

コマンド入力なしで起動する場合は、Macでは`run_tapo_splitter.command`、Windowsでは`run_tapo_splitter.bat`をダブルクリックしてください。ランチャーは同梱または親フォルダの仮想環境を優先し、なければ通常のPythonを使用します。Macで初回だけ開けない場合は、ファイルを右クリックして「開く」を選びます。

初回起動時はターミナル上で、録画データフォルダと分割結果の出力フォルダを指定します。動画の解像度に合う読み取り設定を選び、その設定用の数字の見本データを使用します。見本データがまだない場合は、初回設定の中で自動作成します。付属の`tapo_osd_seed.json`は、最初の読み取りを助ける補助データです。読み取りやすい場面は自動で進み、判断が難しい場面だけ利用者に確認します。確認した結果から、その環境向けの見本セットを作成します。

同じ解像度の読み取り設定を複数登録する場合は、使用するものだけを有効にしてください。解像度に合う設定がない、または複数ある場合は、間違った見本で処理せず停止します。

読み取り設定を切り替えると、数字の見本だけでなく、日時表示を探す範囲と14個の文字位置も一緒に切り替わります。

既存JSONを完全に作り直す場合は、次のように`--fresh`を付けて実行します。

```bash
python3 build_tapo_osd_glyph_templates.py --fresh --profile-id tapo_c230_3k --output tapo_osd_glyph_templates.json
```

OSDが映っていない、または14桁の日時を切り出せない録画では、テンプレートJSONを作成できず処理を中止します。その場合はOSDが表示されている録画を用意して再実行してください。

設定ファイルに録画フォルダ・出力フォルダ・並列数・Profile定義ファイルが保存された後は、次回から初期設定を省略して本番の分割処理を開始します。

通常利用では設定ファイルを直接編集する必要はありません。録画フォルダ、出力フォルダ、並列処理数を変更する場合は、次のように実行します。読み取り設定を追加・切り替えする場合だけ、`tapo_profiles.json`を変更します。

```bash
python3 run_tapo_splitter.py --setup
```

各項目でEnterのみを押すと現在の設定を維持します。Windowsでは`py run_tapo_splitter.py --setup`を使用してください。数字の見本JSONは自動管理されるため、場所を指定する必要はありません。

## 動作の概要

1. 録画映像から日時表示の範囲を切り抜き、最初の補助データまたは利用者が確認した日時と一緒に数字の見本を作成します。
2. その見本を使って、録画ファイル内の日時表示を順に読み取ります。
3. まず通常の明るい文字として読み取り、難しい場面では見え方を変えた複数の方法で読み直します。
4. 映像上の経過時間とOSD時刻の差を調べ、時刻が不連続になった位置をジャンプとして検出します。
5. 検出位置を基準に、画質を変えずにMOVへ分割します。
6. 分割一覧と、録画停止が疑われる区間の情報をMarkdownで保存します。

内部では、文字の高さや並び方も確認しながら、読み間違いが疑われる場面だけ別の見え方で再確認します。詳しい処理方式や用語の説明は、プロジェクトのNotion技術資料を参照してください。

## ライセンスについて

このツールは利用者の録画から作成したテンプレートJSONを使用します。特定フォントのデータを配布物へ同梱しないため、フォントライセンスに依存しない構成です。
